# Month 01 — Production-Directed Foundation

Month 01 berisi 30 work packet berurutan. Target akhirnya adalah **Production-Directed Engineering Alpha Candidate — Lab Use Only** dan `.fsnap` v0.1 Analysis Contract Freeze, bukan production.

- Week 1: repository, boundaries, domain state, audit, dan canonical hashing.
- Week 2: synthetic acquisition, RAW/split-RAW, `.fsnap`, dan verifier independen.
- Week 3: Tauri UI, guidance, reporting, CI, DevSecOps, dan fuzz/property baseline.
- Week 4: feasibility tiga OS, performance baseline, documentation, adversarial review, dan alpha gate.

Satu Day boleh memerlukan lebih dari satu hari kalender. Day berikutnya tidak dimulai sebelum exit gate Day aktif menjadi `EXPECTED_PASS` setelah independent review.

Semua physical-device operation memakai `MANUAL_START`; raw disk, privilege, real evidence, signing, release, atau perubahan RFC berhenti pada `HUMAN_APPROVAL_REQUIRED`.
