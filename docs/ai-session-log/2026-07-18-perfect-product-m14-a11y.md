# Perfect Product M14 — accessibility and SOP copy

## Delivered

- Help/SOP copy is available as EN/ID Slint string properties for write blockers,
  out-of-validation decisions, hash seals versus signatures, format limits, and keyboard use.
- Product IA documents Cases, Identify, Acquire, Preserve, Triage/Tools, and Help/QMS/About as
  separate operator surfaces.
- Light theme is the intended first-use default in the design brief; dark remains a preference.

## Accessibility checklist

- [x] Operator-facing help uses plain, action-oriented language.
- [x] EN and ID strings preserve the same safety boundary.
- [x] Hash seal copy explicitly says it is not a digital signature.
- [x] Keyboard focus and basic navigation are described.
- [ ] Verify focus order and focus contrast with a running desktop build.
- [ ] Verify screen-reader exposure with the supported platform assistive technology.
- [ ] Run keyboard-only acquisition rehearsal with an operator.
- [ ] Obtain human accessibility review before a production claim.

AI prepared this checklist; it is not an accessibility conformance approval.
