# `.fsnap` v0.1 Read Contract (Draft — Freeze Candidate)

Result class: **Engineering Alpha**. This is a **freeze candidate** draft
contract for the `trareon-core::verify_fsnap` / `trareon-verifier` reader
against the `.fsnap` v0.1 package layout produced by
`trareon-core::create_fsnap`. It is not a final format specification and
carries no production compatibility promise. See
`docs/CAPABILITY-MATRIX-M0.md` for freeze blockers.

## Package layout

A `.fsnap` v0.1 package is a directory containing exactly:

```
<package>/manifest/manifest.json
<package>/audit/audit.jsonl
<package>/acquisitions/0001/evidence.raw
```

No other regular file may exist anywhere under `<package>`, and no entry may
be a symlink. See `schemas/fsnap-manifest-v1.schema.json` for the manifest's
JSON Schema.

## Reader behavior: no silent repair

The reader (`verify_fsnap`) is fail-closed. On any of the following
conditions it returns an error and never returns a partially-valid or
"repaired" manifest — there is no silent correction, no best-effort
recovery, and no partial-success result:

| Condition | Rejected by |
|---|---|
| Manifest path is absolute, contains `..`, backslash, or NUL | `resolve_within_package` path-safety check |
| A declared path resolves outside the package directory | canonical-path containment check |
| Any package entry is a symlink | `symlink_metadata` check on every declared path and every directory entry |
| A regular file exists that isn't `manifest/manifest.json` or the two manifest-declared paths | `collect_regular_files` allow-list check |
| Evidence file size doesn't match `evidence_size` | size comparison before hashing |
| Evidence file SHA-256 doesn't match `evidence_sha256` | SHA-256 recomputation |
| Audit file SHA-256 doesn't match `audit_sha256` | SHA-256 recomputation |
| Audit hash chain has a sequence gap, broken previous-hash linkage, or a recomputed event hash mismatch | `AuditJournal::verify` (called via `read_jsonl`) |
| Recomputed audit root doesn't match `manifest.audit_root` | root comparison after journal verification |
| `manifest.schema` isn't exactly `"trareon.fsnap.manifest/1"` | schema string equality check |
| `manifest.build_identity` doesn't match this build's `build_identity()` | build-identity string equality check |
| Any regular file is missing, or any path fails to canonicalize | I/O error propagation |

Every rejection surfaces as `CoreError::Verification` or `CoreError::Io`, and
the CLI (`trareon-verifier verify PATH`) maps every error to exit code `2`
with an `INVALID <message>` line on stderr. Exit code `0` (`VALID <sha256>
<size>` on stdout) is returned only when **every** check above passes.

## Golden fixtures

`fixtures/fsnap-v0.1/` contains six committed, deterministic packages
exercised by `crates/trareon-verifier/tests/cli.rs`:

| Fixture | Expected `trareon-verifier` exit code | What it proves |
|---|---:|---|
| `valid/` | `0` | An untouched package is accepted |
| `mutated/` | `2` | Changed evidence bytes are rejected (SHA-256 mismatch) |
| `truncated/` | `2` | Evidence shorter than `evidence_size` is rejected |
| `removed-file/` | `2` | A missing declared file (`audit.jsonl` deleted) is rejected |
| `audit-discontinuous/` | `2` | A broken audit hash chain is rejected |
| `unsupported-version/` | `2` | An unrecognized `manifest.schema` value is rejected |

Regenerate the fixtures deliberately (they are not regenerated by the normal
test suite) with:

```bash
cargo test -p trareon-verifier --test generate_fixtures -- --ignored --nocapture
```

## Non-goals of this draft

- No forward/backward compatibility guarantee across `.fsnap` schema
  versions — `unsupported_version` is rejected outright, not migrated.
- No partial-read API — the contract is all-or-nothing per package.
- No support for reading a package while it is being written concurrently.
- Split-RAW multi-segment evidence packaging is not yet part of this
  contract; `create_fsnap`/`verify_fsnap` still assume a single
  `evidence.raw` file (see `docs/WEEK-01-DISCREPANCY-REGISTER.md`).
