# Trareon Acquire Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a seven-day engineering foundation that acquires a synthetic/file-backed source into RAW, records a hash-chained audit, creates a minimal `.fsnap` directory package, verifies it independently, and exposes the workflow through a minimal Tauri desktop shell.

**Architecture:** `trareon-core` owns every state transition, byte read/write, hash, manifest, and verification decision. `trareon-verifier` is an independent CLI consumer of the package. Tauri/Svelte is an untrusted presentation adapter that invokes typed Rust commands and never determines final acquisition status.

**Tech Stack:** Rust 1.95.0 edition 2024, Tauri 2.11.5, Svelte 5.56.5, TypeScript 7.0.2, Vite 8.1.5, Node 22.22.3, npm 10.9.8, GitHub Actions, SHA-256, JSON/JSONL.

## Global Constraints

- This plan produces `Engineering Alpha`, never `Official Production`.
- No raw device, driver, root/admin execution, E01/AFF4, RAM, mobile, cloud, or network capture is introduced.
- All Rust dependencies use exact versions in the generated lockfile; all npm dependencies use exact versions and `npm ci`.
- Core logic has no dependency on Tauri, WebView, or frontend types.
- Frontend never receives arbitrary filesystem permission and never invokes a shell.
- Every failure leaves an explicit non-complete state and an audit record.
- Tests use only generated bytes under temporary directories.
- No real case data, device path, credential, or personal data enters CI.
- Every task ends with tests and a reviewable commit.

```rust
use serde::{Deserialize, Serialize};
use thiserror::Error;
use uuid::Uuid;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize)]
#[serde(transparent)]
pub struct CaseId(pub Uuid);

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize)]
#[serde(transparent)]
pub struct AcquisitionId(pub Uuid);

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum AcquisitionState {
    Planned,
    PreflightPassed,
    Acquiring,
    AcquiredUnverified,
    Verifying,
    VerifiedComplete,
    Failed,
    Cancelled,
}

#[derive(Debug, Error, PartialEq, Eq)]
pub enum CoreError {
    #[error("invalid acquisition transition from {from:?} to {to:?}")]
    InvalidTransition {
        from: AcquisitionState,
        to: AcquisitionState,
    },
    #[error("I/O error: {0}")]
    Io(String),
    #[error("serialization error: {0}")]
    Serialization(String),
    #[error("verification failed: {0}")]
    Verification(String),
}

impl AcquisitionState {
    pub fn transition(self, next: Self) -> Result<Self, CoreError> {
        let allowed = matches!(
            (self, next),
            (Self::Planned, Self::PreflightPassed)
                | (Self::PreflightPassed, Self::Acquiring)
                | (Self::Acquiring, Self::AcquiredUnverified)
                | (Self::AcquiredUnverified, Self::Verifying)
                | (Self::Verifying, Self::VerifiedComplete)
                | (Self::Planned, Self::Cancelled)
                | (Self::PreflightPassed, Self::Cancelled)
                | (Self::Acquiring, Self::Cancelled)
                | (Self::Acquiring, Self::Failed)
                | (Self::AcquiredUnverified, Self::Failed)
                | (Self::Verifying, Self::Failed)
        );
        allowed.then_some(next).ok_or(CoreError::InvalidTransition {
            from: self,
            to: next,
        })
    }
}
```

- [ ] **Step 3: Implement minimal streaming acquisition**

Create `acquisition.rs` using a fixed 1 MiB buffer. Canonicalize source and destination parent paths, reject identical paths, reject missing/empty source, create output with `create_new(true)`, and transition only through `Planned -> PreflightPassed -> Acquiring -> AcquiredUnverified`. Hash every byte read before writing it. After the loop call `flush()` and `sync_all()`. On read/write/sync failure, remove no output, return `CoreError::Io`, and never return a complete summary.

Expose these exact public types:

```rust
#[derive(Debug, Clone)]
pub struct AcquireRequest {
    pub source: std::path::PathBuf,
    pub output: std::path::PathBuf,
    pub audit_output: std::path::PathBuf,
    pub buffer_size: usize,
}

impl AcquireRequest {
    pub fn new(source: impl Into<std::path::PathBuf>, output: impl Into<std::path::PathBuf>) -> Self {
        let output = output.into();
        let audit_output = output.with_extension("audit.jsonl");
        Self { source: source.into(), output, audit_output, buffer_size: 1024 * 1024 }
    }
}

#[derive(Debug, Clone, serde::Serialize, serde::Deserialize)]
pub struct AcquisitionSummary {
    pub bytes_read: u64,
    pub bytes_written: u64,
    pub sha256: String,
    pub audit_root: String,
    pub audit_path: std::path::PathBuf,
    pub state: AcquisitionState,
}

pub fn acquire_file(request: &AcquireRequest) -> Result<AcquisitionSummary, CoreError>;
```

The implementation creates one `AcquisitionId`, appends `planned`, `preflight_passed`, `acquiring`, and `acquired_unverified` events at their real transition boundaries, verifies the journal, writes it to `request.audit_output`, and returns its verified root and path. An I/O failure appends `failed` when the journal itself remains writable; inability to persist that event is returned as an additional explicit error rather than hidden.

Export the module API from `lib.rs`.
