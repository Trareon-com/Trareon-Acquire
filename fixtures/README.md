# Fixtures

Everything under this directory (and every fixture generated by the test
suite or the foundation demo) is synthetic. It is created locally by a test,
a script, or the `dd`/`fs::write` commands in `docs/FOUNDATION-DEMO.md`.

- No file here is, or is derived from, real forensic evidence.
- No file here is accepted as validation data for any capability claim.
- Fixtures exist only to exercise byte-for-byte copy, hashing, audit-chain,
  package, and verifier behavior in a repeatable, non-sensitive way.

Real evidence, disk images, or case data must never be committed to this
repository or any fixture directory.
